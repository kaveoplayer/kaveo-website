## What it is for

These work while a video is playing, and every one of them can be changed — see
[Shortcuts](settings/shortcuts.md), which lists one fewer on Linux.

| What it does | Default shortcut |
|---|---|
| Play / Pause | **Space** |
| Seek forward (+10s) | **→**, **Mouse Fwd**, **Wheel →** |
| Seek backward (-10s) | **←**, **Mouse Back**, **Wheel ←** |
| Frame step forward | **.** |
| Frame step backward | **,** |
| Speed up | **]** |
| Speed down | **[** |
| Volume up | **↑**, **=**, **Wheel ↑** |
| Volume down | **↓**, **-**, **Wheel ↓** |
| Mute | **M** |
| Cycle audio track | **A** |
| Cycle subtitle track | **S** |
| Toggle statistics overlay | **I** |
| Reset statistics | **R** |
| Stats: next page | **Tab** |
| Toggle fullscreen | **F11**, **Enter**, **Enter (num)**, **Wheel Click** |
| Toggle exclusive fullscreen (Mode 1) | **F** |
| Audio delay −50 ms | **K** |
| Audio delay +50 ms | **L** |
| Subtitle delay −50 ms | **Z** |
| Subtitle delay +50 ms | **X** |
| Subtitle delay −500 ms | **Shift+Z** |
| Subtitle delay +500 ms | **Shift+X** |
| Zoom in | — |
| Zoom out | — |
| Reset picture placement | — |
| Toggle pan and scan (fill the screen) | — |
| Subtitle editor | **E** |
| Save frame | **Shift+S** |
| Copy frame | **Ctrl+C** |

Three more keys cannot be changed:

- **Esc** leaves fullscreen, on any screen.
- **F12** saves a picture of what is on screen — see [Screenshots](watching/screenshots.md).
- **Ctrl+H** opens the live picture panel while a film plays.

## Good to know

- The four actions with a dash have no shortcut until you give them one.
- A shortcut can be a mouse button or a wheel notch as readily as a key, so some rows carry both.
- **Toggle exclusive fullscreen (Mode 1)** has no Settings row outside Windows, where **F** is ordinary fullscreen.
