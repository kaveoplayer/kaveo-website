## What it is for

**Settings › Interface** covers how Kaveo itself looks — language, themes, hover previews and the
featured band — plus whether it appears in your desktop's menus and media controls.

![Settings shown on the Interface section: the rail listing all sixteen sections with Interface selected under App, and beside it the eight rows — Language on English, App theme and Player theme on Dark, Hover preview on Clip from the video, Featured background on Gradient rather than the default Title artwork, System media controls and Seek bar previews ticked, and File manager integration unticked.](../images/settings/interface.webp)

## How to use it

1. Pick a **Language**: **English**, **Italiano**, **Français** or **Español**. It changes Kaveo's
   wording, not a film's audio or subtitle track.
2. Choose an **App theme** for the library and a **Player theme** for what surrounds a film —
   separately, from **Dark** (where Kaveo starts), **Light**, **Pure black (OLED)**,
   **High contrast**, **Warm night** and **Indigo**.
3. Set **Hover preview** to **Clip from the video**, the default, or **YouTube trailer**; a
   server's title always plays its trailer.
4. Set **Trailer quality** and **Trailer language**; see [Trailers](../library/trailers.md).
5. Set **Featured background** to **Title artwork** — the default — or **Gradient**; see
   [The library home](../library/home.md).
6. Leave **System media controls** ticked for the media keys; see
   [Media keys and the desktop](../watching/media-keys.md). Tick **File manager integration** to put
   Kaveo in your desktop's right-click menus; see [From your file manager](../file-manager.md).
7. Untick **Seek bar previews** to show only the time and chapter over the playback bar.

## Good to know

- Every row but **File manager integration** waits for **Save**; the language, the themes,
  **System media controls** and **Seek bar previews** change as you pick them; **Revert** undoes them.
- That one acts the moment you tick it, and **Revert** does not undo it; a desktop that cannot
  offer the menus says *Not available on this desktop.*
