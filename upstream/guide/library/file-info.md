## What it is for

See a title's file as it is on disk — its name, its folder, the name it had before Kaveo imported
it, and everything its container declares — when you need to know what a file really is.

## How to use it

1. Right-click the card and choose **File info…**, or click **⋯** on the title's page and choose it there.
2. For a series or an album, pick the file from the list at the top.
3. Read the **File**, **Container** and **Streams** sections; any value can be selected and copied.
4. Click **Copy path** or **Open containing folder** to take the file elsewhere.

## Good to know

- **Before import** shows the name a file was downloaded under, for files Kaveo moved itself.
- The container and its streams are read with FFprobe; without it only the file and its folder are shown.
- Server and hidden titles have no file info: their files are not on this computer.
