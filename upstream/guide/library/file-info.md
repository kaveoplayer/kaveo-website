## What it is for

See everything about a title in one place: what the library knows and its file, on this computer,
in a network folder or on your server, with everything its container declares.

## How to use it

1. Right-click the card and choose **Properties…**, or choose it from **⋯** on the title's page.
2. For a series or an album, pick the file from the list at the top. A title in more than one place (here, a network folder, your server) also has a **Copy** list.
3. Read the **Overview**, **File**, **Container** and **Streams** sections; any value can be selected, and the TMDB and IMDb ids have a copy button.
4. For a file on this computer, click **Copy path** or **Open containing folder**.

## Good to know

- **Before import** shows the name a file was downloaded under.
- A local file is read by Kaveo itself, with nothing to install; a server copy's details come from the server. If it does not answer, click **Retry**.
- A file in a network folder is read through its connection when you open the dialog, and the **File** section names the connection. If the folder does not answer, click **Retry**; on a metered connection the dialog says it read over it.
- A hidden title shows only its **Overview**.
