## What it is for

See everything about a title in one place: what the library knows and its file, on this computer
or on your server, with everything its container declares.

## How to use it

1. Right-click the card and choose **Properties…**, or choose it from **⋯** on the title's page.
2. For a series or an album, pick the file from the list at the top. A title both here and on your server also has a **Copy** list.
3. Read the **Overview**, **File**, **Container** and **Streams** sections; any value can be selected, and the TMDB and IMDb ids have a copy button.
4. For a file on this computer, click **Copy path** or **Open containing folder**.

## Good to know

- **Before import** shows the name a file was downloaded under.
- A local file is read with FFprobe; a server copy's details come from the server. If it does not answer, click **Retry**.
- A hidden title shows only its **Overview**.
