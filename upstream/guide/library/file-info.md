## What it is for

See everything about a title in one place: what the library knows — its titles, year, genres,
provider ids, where it comes from — and its file as it is on disk, with the name it had before Kaveo
imported it and everything its container declares.

## How to use it

1. Right-click the card and choose **Properties…**, or click **⋯** on the title's page and choose it there.
2. For a series or an album, pick the file from the list at the top.
3. Read the **Overview**, **File**, **Container** and **Streams** sections; any value can be selected and copied, and the TMDB and IMDb ids have a copy button.
4. Click **Copy path** or **Open containing folder** to take the file elsewhere.

## Good to know

- **Before import** shows the name a file was downloaded under, for files Kaveo moved itself.
- The container and its streams are read with FFprobe; without it only the file and its folder are shown.
- A hidden title shows only its **Overview**: nothing that names its file.
- Server titles do not offer **Properties…** yet.
