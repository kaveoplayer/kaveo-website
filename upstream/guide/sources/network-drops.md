## What it is for

When a title from a network folder stops reading, Kaveo holds the picture where it is and says why,
so it never looks frozen for no reason.

## How to use it

1. The middle of the screen says **Waiting for the server…**, then **Reconnecting to the server…**.
2. When the server answers, the message goes and the title goes on from where it stopped.
3. If it stays down for about two minutes, or the file changed, it says **Playback stopped here** and why.
4. If it says **It goes on by itself when the server answers again.**, wait; otherwise click **Retry** or press Enter.

## Good to know

- A refused password offers no **Retry**: change it on **Sources**, then play the title again.
- Esc leaves the player whatever the message says.
- The statistics panel (I, then Tab to **MEDIA**) shows the connection's speed and errors.
