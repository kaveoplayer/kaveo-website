## What it is for

A file you copy onto your Jellyfin server yourself, such as a subtitle beside an episode, stays
invisible until the server looks for it. Kaveo can ask the server to look.

## How to use it

1. For one title, right-click its card or click **⋯** on its page or its episode row, and choose
   **Scan for new files on the server**. On a series it covers every episode.
2. While an episode plays, right-click the picture and open **Subtitles** › **Tools** ›
   **Look for new subtitle files on the server**. Kaveo waits up to half a minute and says how many
   new files appeared.
3. For everything, click **Scan libraries** on the **Sources** page.

## Good to know

- Only a Jellyfin administrator account can ask for a scan; any other account is told so.
- The library updates by itself when the server finishes. **Reload** only asks the server again for
  what it already lists.
