## What it is for

Save exactly what Kaveo is showing — a video and its controls, or any other screen — as a picture
file.

## How to use it

1. Press **F12** anywhere in Kaveo: in the library, in Settings, or while a video plays.
2. Kaveo saves it as a PNG file in a *screenshots* folder inside its cache folder:
   - on Linux, the *kaveo* folder inside the hidden *.cache* folder in your home folder;
   - on Windows, *AppData\Local\kaveo\cache*, a *screenshots* folder inside.
3. Kaveo shows no message when it saves one — look for the new file in that folder.

## Good to know

- While a private title is open in the player, even behind another screen, Kaveo refuses the capture
  and says *No screenshot: this title is hidden*.
- Each file is named with a number that grows, so the newest screenshot has the largest number.
- On Windows, **F12** takes no screenshot while a video is in exclusive fullscreen.
